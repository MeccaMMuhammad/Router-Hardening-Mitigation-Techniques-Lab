# Router-Hardening-Mitigation-Techniques-Lab
This repository contains all the configuration steps and command-line instructions for completing a hands-on lab focused on router security hardening, access control, encryption, and monitoring. This lab uses Cisco 2911 routers and is divided into three exercises.
🔐 Lab Overview

Learning Outcomes

Review and configure router settings and credentials.

Secure remote access using SSH.

Harden router by disabling unused services and restricting access.

Configure NTP and enable router logging.
